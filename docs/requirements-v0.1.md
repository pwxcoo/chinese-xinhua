# 字间：纵横字谜 — 需求基线 v0.1

- 状态：首版实现；基线日期：2026-11-05。
- 产品版本：0.1.0。后续需求通过 GitHub Issue/PR 变更，修改本文版本和 CHANGELOG；保留既有版本文档。
- 目标：使用现有新华词库，实现手机和电脑均可玩的单人成语纵横填词网页。

## 本版产品决定

- 首版聚焦四字成语。双字词和多字词、单字详情、歇后语为后续范围；不把“混合长度词库”标记为已实现。
- 难度目前通过词条数量、棋盘规模、预填比例和候选字区分，尚无词频等级或经过玩家实测的难度标定。
- 每条至少有一个预填字；候选字来自当前词条并去重，降低简单关门槛。
- 星级：未揭示为 3 星；揭示 1 字为 2 星；揭示至少 2 字为 1 星。检查次数单独记录，不扣星。
- 用时是首次进入至通关的经过时间，包含离开页面的时间；不设倒计时。
- 不要求注册；进度仅保存在当前浏览器，清除网站数据后丢失；不支持跨设备同步。
- 关卡解锁是游戏体验机制，不是安全限制；静态资源包含答案。
- 布局具有确定答案，尚不保证自然语言释义在完整汉语词库中唯一。正式扩展题库前需做歧义审核。
- 原始词库不改写；词库子集保留上游释义，整体内容准确性与适龄性仍需逐步人工审核。

## 版本变更方式

1. 新需求或缺陷建立 GitHub Issue，注明 R/N 编号、验收标准和目标版本。
2. 实现 PR 引用 Issue，并同步版本、需求状态、CHANGELOG 和测试记录。
3. 改动词库/生成算法时升级本地存储键，避免既有填写与新布局错位。
4. 发布版本以 Git 提交/标签定位；站点部署作为独立步骤记录，不将代码推送视为已上线。
